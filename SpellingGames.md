# Weekly school-list spelling games

These use `englishWordsAM.json` / `frenchWordsAM.json`.

| Game | What the child does |
|---|---|
| **Eng/Fr Spelling (Jumble)** | Hear the word, tap/drag letters from a bank to spell it. Easy/hard days change difficulty. This is the classic jumble. |
| **Spelling Drag** | Per word: drag letters (and syllables if the JSON has them), then a memory round with the word hidden. School lists have no syllables, so it skips the syllable round. |
| **Word Garden** | Plant letters into garden plots in order to spell the word. |
| **Word Fishing** | Cast and catch letter-fish to spell the word. |
| **Word Factory** | Pick letters off a moving conveyor belt to spell the word. |
| **Snake Catch** | Steer a snake to eat letters in the right order. |
| **Spelling Race** | Type/build the word while racing a bot down a track. AM already has this for English. |
| **Spelling OCR** | Hear the word, **write it by hand**; the app reads the writing. Good handwriting + spelling check. |
| **Jumble Photo** | Shows the week’s list and has the child photograph written work (not a letter-building game). |

If you want a smaller set, the usual core is **Jumble + OCR**, plus one or two of Garden/Fishing/Factory for variety.

# UFLI games

| Game | What it is | This sheet maps to |
|---|---|---|
| **UFLI Word Chain** | Slider: start with a seed word, then change one part (`just → rust → rest → west`). | Loaded: both chains + sample words as extra “Build ___.” rounds |
| **UFLI Irregular Words** | Tap letters/graphemes to spell heart words. | Loaded: look, book, are, was, you, what, have |
| **UFLI Words** | Native tap-tile spelling of **sample/concept words** (not chains). | Loaded AM-only file: hand, fast, best, list, stop, jump |
| **English reading (tappable book)** | Read a UFLI **decodable passage**, tap words, answer questions. | Not this Home Practice page (needs a story JSON) |
| **UFLI Home Videos** | Sequential lesson videos. | Not from this PDF |
| **French UFLI** | Opens the French UFLI site. | Unrelated to this English sheet |

The two Home Practice **sentences** (“He went to get help.” / “What is the best spot?”) are not used by any UFLI game. Sentence Builder is a separate English-sentence bank.
