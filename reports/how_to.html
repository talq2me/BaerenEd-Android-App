  1. Toggle spelling: School Mode ↔ Summer Mode

Toggle spelling from School Mode to Summer Mode

Spelling is split into two systems. Rotating-pool games share a word list and progress key across Drag, Garden, Fishing, Race, Factory, and Snake Catch. School-list games always use the weekly school JSON files directly.

Rotating-pool games (Summer Mode)

These games use the shared spelling pool (same words across games that share a poolKey):

  • Spelling Drag
  • Word Garden
  • Word Fishing
  • Spelling Race
  • Word Factory
  • Snake Catch

School-list games (always on school JSON)

  • Fr / Eng Spelling Jumble
  • Spelling OCR

Update the school word files (frenchWordsAM.json, englishWordsBM.json, etc.) each week for Jumble and OCR. The rotating-pool games are configured separately in the schedule URLs.

URL parameters (rotating-pool games)

Each rotating-pool task URL includes query parameters like:

?file=spellingDragFrBM.json&pool=5&poolKey=frSpellingDrag

file — master word list (100-word rotating lists: spellingDragFrAM.json / spellingDragEnAM.json for AM, spellingDragFrBM.json / spellingDragEnBM.json for BM)

pool=5 (Summer Mode) — 5 words per session from the rotating index; same 5 all day across games sharing the poolKey

pool=all (School Mode only) — entire school list each session; use with frenchWordsBM.json / englishWordsAM.json etc. instead of spellingDrag*

poolKey — frSpellingDrag or engSpellingDrag. All required games with the same poolKey get the same words that day. Practice tasks use separate keys (frSpellingDragPractice, etc.).

When all required work for the day is finished, the pool index advances by 5 words (Toronto calendar day), so the rotating master list progresses over time during Summer Mode.

Spelling Drag rounds

Spelling Drag has three rounds per word (when syllables exist in the JSON):

  1. Star 1 — drag syllables while the word is displayed
  2. Star 2 — drag letters while the word is displayed
  3. Star 3 — spell from memory (word hidden, audio only)

School word files (frenchWordsBM.json, etc.) do not include syllables, so Drag skips round 1 and only does letters → blind (2 stars max). To get the syllable round on school words, the JSON would need syllable data (as in the spellingDrag* files).

Switch rotating-pool games to School Mode

School mode

In Schedule Editor (or AM_config.json / BM_config.json), for each rotating-pool spelling game URL:

  1. Change file= to the school list for that profile:
    ProfileFrench school listEnglish school list
    AMfrenchWordsAM.jsonenglishWordsAM.json
    BMfrenchWordsBM.jsonenglishWordsBM.json
  2. Keep pool=5 and the same poolKey (frSpellingDrag or engSpellingDrag) so all pooled games still share the same words.
  3. Replace the weekly words in the school JSON on GitHub (same files Jumble and OCR use).
  4. Publish config + data to GitHub Pages so tablets load the update.

Example school-mode French URL: ...SpellingDrag.html?file=frenchWordsBM.json&pool=all&poolKey=frSpellingDrag

With pool=all, every session uses the full school list. All pooled games stay in sync because they share the same poolKey.

Switch rotating-pool games back to Summer Mode

Summer mode

  1. Change file= back to the rotating master list:
    ProfileFrench rotating listEnglish rotating list
    AMspellingDragFrAM.jsonspellingDragEnAM.json
    BMspellingDragFrBM.jsonspellingDragEnBM.json
  2. Keep pool=5 and poolKey unchanged.
  3. Publish updated config to GitHub Pages.

Example summer-mode French URL: ...SpellingDrag.html?file=spellingDragFrBM.json&pool=5&poolKey=frSpellingDrag

The 100-word master lists do not need weekly edits; the pool index advances automatically when required daily work is complete.
